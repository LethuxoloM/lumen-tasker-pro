# Lethuxolo's AI Suite (22)

Create a modern, responsive full-stack SaaS web application called "Lethuxolo's AI Productivity Suite." The design style must be clean, modern, and professional with a sleek dark theme, deep dark-gray backgrounds, slate card containers and electric blue accents. Navigation and layout structure : sidebar navigation: a collapsible left sidebar with navigation links to: 1. Dashboard (overview metrics, quick-start tools, and recent AI generations)  2. Smart Email Generator 3. Meeting Notes Summarizer 4. AI Task Planner 4. AI Assistant Chatbot. Top Header: Display workspace title, universal search bar, user profile indicator and dark/light theme toggle. Footer Disclaimer: include a persistent, subtle "Responsible AI Disclaimer " banner at the bottom stating: "AI-generated outputs may contain inaccurate. Please review and verify key details before publishing". Core Tool Dashboards and modules: Smart Email Generator: 1. from inputs: Recipient, Goal/Indent, Tone selector (professional, casual  , urgent persuasive) and key points text area 2. Features: "Generate email" button, structured prompt output container area , " Copy to clipboard" button, and tone switcher. 2. Meeting notes summarizer: 1. from inputs: meeting title, date, raw transcript/notes upload or paste box. 2. features: Actionable output section generating "Executive Summary" "key action items" and "decision made". All generated sections must be directly editable. 3. AI Task Planner: input field:  Goal or Project Description e.g (launch app MVP 2 weeks)  Features: interactive task board ( kanban/list view) breaking down the goal into prioritized sub tasks, estimated durations, and category tags. Users can add, edit or mark tasks complete.  4. AI Chatbot Interface: Layout: Clean chat workspace with message history, typing indicators suggested quick prompts ("summarize this text", " draft a follow-up") and an input box supporting multi-line text and send triggers. Technical and UI Requirements: 1. Use Tailwaind CSS with rounded corners , subtle borders and smooth hover transitions. Interactive React state management across all tabs so outputs are live-editable, copyable and removeable.
